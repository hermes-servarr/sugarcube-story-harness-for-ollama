# Candidate Capability Probes

Candidate probes are data-only diagnostics executed by signed code. Save one
JSON object per file under `benchmark_optimization/candidate_tests/`.

Required fields:

```json
{
  "schema_version": 1,
  "id": "CAND-T6-RETRIEVE-XL-02",
  "tier": 6,
  "context_ref": "scifi",
  "context_size": "XL",
  "task_complexity": "K1",
  "distractor_density": "D0",
  "variant": "compact",
  "direction_key": "C",
  "task": "Write a complete short passage that states the archive code from context. Include at least two choices.",
  "checks": [
    {"check": "sections"},
    {"check": "context_needle", "name": "archive_code"},
    {"check": "min_choices", "count": 2},
    {"check": "no_markdown"}
  ]
}
```

Allowed enums:

- `tier`: integer 0-9.
- `context_ref`: `fantasy`, `scifi`, `horror`, `modern`, `cyberpunk`,
  `complex_state`, `social`, or `puzzle`.
- `context_size`: `S`, `M`, `L`, or `XL`.
- `task_complexity`: `K1`, `K2`, `K3`, or `K4`.
- `distractor_density`: `D0` or `D1`.
- `variant`: `compact`, `full`, `json`, or `thinking`.
- `direction_key`: `A` through `H`, selected for the closest canonical
  SugarCube behavior.

Allowed checks:

```json
{"check": "sections"}
{"check": "contains", "value": "literal text"}
{"check": "absent", "value": "literal text"}
{"check": "macro", "name": "set"}
{"check": "variable", "name": "$hasKey"}
{"check": "context_needle", "name": "archive_code"}
{"check": "context_needle", "name": "treaty_name"}
{"check": "context_needle", "name": "witness_name"}
{"check": "min_choices", "count": 2}
{"check": "balanced_macro", "name": "if"}
{"check": "no_markdown"}
```

Use 3-12 checks. At least one must be `macro`, `variable`,
`context_needle`, `min_choices`, or `balanced_macro`. All checks must pass;
the probe cannot set a threshold or verdict.

Keep `task` under 1,500 characters. It may describe SugarCube output but must
not contain URLs, model identities, private data, commands for the operator,
or benchmark results. Context text is generated by signed code; a probe only
selects its trusted profile and size.
