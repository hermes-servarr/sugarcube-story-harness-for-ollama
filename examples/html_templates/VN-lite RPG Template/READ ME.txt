========Notes:
This template was inspired by text-focused Visual Novels interface (like the Narrat system) and RPG games like Disco Elysium. Along with passages, it will leave space for atmospheric backgrounds and PC/NPC portraits. It includes notes and annotations in both the different passages, JavaScript and StyleSheet.

The CSS codes include a "Table of Content" to find different sections easier, ordered by types of elements.

I highly recommend W3 schools (for CSS Beginner) and MDN (for more advanced code) if you encounter an unknown CSS reference or are looking for a specific one.

If you have any question about or any issue with the template, send me an ask over on Tumblr or comment on the asset page.
