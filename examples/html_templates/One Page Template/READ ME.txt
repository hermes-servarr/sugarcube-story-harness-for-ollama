========Notes:
This template tries to emulate the look of the Chapbook format, with its one page display, while accommodating SugarCube features (Settings/Saves). It comes with basic accessibility features (text + saves + themes). It includes notes and annotations in both the different passages, JavaScript and StyleSheet.

The CSS and JavaScript code include "Table of Contents" to find different sections easier. Both are organized by type of code/elements.

I highly recommend W3 schools (for CSS Beginner) and MDN (for more advanced code) if you encounter an unknown CSS reference or are looking for a specific one.

If you have any question about or any issue with the template, send me an ask over on Tumblr or comment on the asset page.
