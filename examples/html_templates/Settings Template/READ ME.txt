========Notes:
This template provides basic Text Display, Save and Accessibility settings (most used/requested in IF circles). While the code is annotated, this template is not a guide on how to use Settings API (you should check my SugarCube Guide instead).

Still I encourage you to use only the settings you want/need, as well as edit them to fit your project. For multiple settings, the required code is spread between the JavaScript and StyleSheet.

The CSS code is organized in a way to separate the different settings, and only there to showcase what the different settings can do. You can edit more than what is coded.

I highly recommend W3 schools (for CSS Beginner) and MDN (for more advanced code) if you encounter an unknown CSS reference or are looking for a specific one.

If you have any question about or any issue with the template, send me an ask over on Tumblr or comment on the asset page.
