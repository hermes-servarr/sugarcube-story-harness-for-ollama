========Notes:
This template provides different ways of creating a Title/Menu page for SugarCube projects. It includes some notes and annotations in the StyleSheet. There isn't any JavaScript included.

The page styling are simply example of what can be done, pretty quickly and simply. You can use them as is (with a bit of editing to fit your project) or as inspiration for a self-created one.

The CSS code is separated between each different title page styling, with clear markers to select, copy and paste. It also includes styling for mobile view.

I highly recommend W3 schools (for CSS Beginner) and MDN (for more advanced code) if you encounter an unknown CSS reference or are looking for a specific one.

If you have any question about or any issue with the template, send me an ask over on Tumblr or comment on the asset page.
